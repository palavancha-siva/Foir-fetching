# LoanSense / Finkuby Backend API

Retail Credit Underwriting & Multi-Bank FOIR Engine REST API.

## Features
- Dynamic FOIR evaluation across multiple banks (HDFC, ICICI, SBI, Poonawalla Fincorp, InCred, Finnable, etc.)
- Multi-tier company categorization (CAT A, CAT B, CAT C, Unlisted / LLPs)
- Pincode serviceability & tier classification
- BRE (Business Rule Engine) policy matrix

## Getting Started
1. Install dependencies: `npm install`
2. Configure `.env` (refer to `.env.example`)
3. Run migrations: `npm run migrate`
4. Start server: `npm start`
